## Rap Lyric Classifier 
A Lyrics based Classifier for our final Project of EECE 5644 Introduction to Machine Learning and Pattern Recognition taught by Stratis Ioannidis at Northeastern University, Boston MA.

## SRC 
SRC has all the code you need to load, preprocess and tokenize the dataset using getDataset.py and the models used to train 

## Install Dependancies 
pip3 install -r requirements.txt

## Results 
The results folder holds various results from our experiments
